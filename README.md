# TapGem

TapGem is a voice-driven desktop environment for the RayNeo X3 Pro smart glasses, built around a Gemini-powered assistant that can open, arrange, and resize windows, browse and control web content, and generate small on-the-fly apps from a spoken request. It runs in two modes: a transparent HUD that floats a few small panels over whatever the wearer is actually doing, and a full desktop with a wallpaper and a proper window manager, both driven by the same touch trackpad and voice commands. The assistant can also see the screen, so it can confirm that a video is actually playing or notice a login wall before acting further, and separate modes handle live spoken translation and language tutoring in the glasses' own voice. Everything renders dark by design, since the waveguide display draws power in proportion to how bright the image is.

## Controls

- Slide on the right trackpad — move the cursor
- Single tap — click what's under the cursor, or start the assistant over empty space
- Hold, then slide — drag a window by its title bar, resize from its corner, or drag content (scroll a page, pan a map)
- Two-finger slide — scroll whatever is under the cursor
- Double tap — start or exit the voice assistant
- Left arm tap — toggle between HUD and desktop mode
